# Мы реализовали задание:

Реализовать следующее состояние «Солнечной системы»: 
- состоит из двух звезд;
- у первой звезды 7 планет, у второй звезды 13 планет;
- на каждой орбите по 1 планете.
Реализовать следующие механики: 
-планеты на четных орбитах всех звезд вращаются по часовой стрелке;
-планеты на нечетных орбитах всех звезд вращаются против часовой стрелки;
- планеты всех звезд между собой не сталкиваются;
- орбиты планет всех звезд пересекаются
- сделать возможным в интерфейсе программы включать и выключать отображение орбит;
